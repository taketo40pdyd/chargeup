貯金のリマインダー

リマインダー

予定の時刻を過ぎても、今日まだ貯金を記録していないときに、ホームにお知らせを出します。

プッシュ通知

アプリを閉じていても、設定した時刻に通知が届きます。通知を送るサーバー（Cloudflare Workersの無料枠）を、あらかじめ用意する必要があります。手順は、付属の README を見てください。

サーバーに送るのは、通知の宛先・曜日と時刻・タイムゾーン・最後に貯金した日付だけです。目標名や金額は送りません。

サーバーの設定

プッシュ通知を使わないときは、アプリを閉じている間は通知を出せません。サーバーを用意せずに確実に知らせてほしいときは、「カレンダーに追加」で、お使いのカレンダーアプリに繰り返しの予定として登録してください。

端数貯金

レシートの金額を入れると、区切りのいい金額に切り上げた差額（端数）を貯金します。

CSV・明細の取り込み

銀行の入出金明細CSVや、このアプリで書き出したCSVを読み込んで、貯金として記録します。ファイルはこの端末の中だけで処理され、外部には送信されません。

取り込み内容の確認

同じ日・同じ金額の記録がすでにあるときは、重複として除きます。取り込む前の状態は、バックアップに自動で残します。

欲しい物リスト

衝動買いを防ぐための「寝かせ」リストです。欲しい物を入れて、決めた日数だけ待ちます。期間が過ぎたら、まだ欲しいかを決めます。

分けて貯金

1回の貯金を、複数の目標に分けて記録します。

    「均等」は同じ金額ずつ、「優先度で重み付け」は目標の優先度に合わせて 高4：中2：低1 の割合で、「残りに比例」は残りが多い目標に多く、「期限が近い順」は必要なペースが高い目標に多く分けます。自動の分け方では、目標の残りを超えては入れず、余った分はほかの目標に回します。
